Freelancer Web Sitesi

Bu proje, freelancer hizmet sağlayıcıları ve iş verenleri bir araya getiren basit bir web uygulamasıdır.Python'un Flask framework'ü ile geliştirilmiştir.

Özellikler

- Kullanıcı kayıt ve giriş sistemi (freelancer & işveren)
- Proje ekleme ve teklif verme modülü
- Kullanıcı profilleri

Teknolojiler

- Backend: Python (Flask)
- Frontend: HTML, CSS, JavaScript (opsiyonel olarak Bootstrap)
- Veritabanı: SQLite / PostgreSQL
- Kimlik Doğrulama: Flask-Login
